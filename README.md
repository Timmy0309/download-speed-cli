# Download speed CLI

Консольная утилита на Node.js: десять раз последовательно скачивает ресурс, считает среднее время запроса, общий объём данных и среднюю скорость скачивания.

## Требования

- Node.js 22 или новее.
- Внешних зависимостей нет.

## Запуск

Из корня проекта:

```sh
npm start -- "https://speed.cloudflare.com/__down?bytes=1000000"
```

Или напрямую:

```sh
node src/cli.mjs "https://speed.cloudflare.com/__down?bytes=1000000"
```

Можно передать любой абсолютный HTTP/HTTPS URL. Для содержательного замера выбирайте достаточно большой файл; доступность и ограничения стороннего сервера зависят от него.

Справка:

```sh
node src/cli.mjs --help
```

После каждого скачивания программа показывает число полученных байтов и длительность, затем выводит итог по всем десяти запросам.

## Единицы и формулы

- Объём: байты тела HTTP-ответа, без заголовков и служебных расходов TCP/TLS.
- Среднее время запроса: миллисекунды, сумма длительностей / 10.
- Скорость: **Мбит/с**, где 1 Мбит = 1 000 000 бит, 1 байт = 8 бит.

```text
totalBytes = сумма байтов десяти ответов
totalSeconds = сумма длительностей десяти запросов в миллисекундах / 1000
speedMbps = totalBytes * 8 / totalSeconds / 1 000 000
```

Это отношение общего объёма к общему времени, а не среднее арифметическое скоростей отдельных запросов.

Время измеряется через `performance.now()`: от начала `fetch` до полного прочтения тела ответа. Оно включает ожидание сервера, установление соединения, когда оно требуется, и перенаправления. Вывод прогресса в консоль в длительности запросов не входит. Округление применяется только при выводе результата.

## Принятые решения

- Следующий запрос начинается только после полного чтения предыдущего ответа.
- Тело читается потоком: считается `chunk.byteLength`, файл не накапливается в памяти и не сохраняется на диск. Наличие `Content-Length` не требуется.
- Используется встроенный `fetch`. Отправляется `Accept-Encoding: identity`. Если сервер всё равно возвращает сжатое тело, измерение завершается с ошибкой: автоматическая распаковка `fetch` могла бы завысить учитываемый объём относительно переданных данных.
- Тайм-аут одного скачивания — **60 секунд**, включая чтение тела ответа.
- HTTP-статус вне 200–299, сетевая ошибка, обрыв тела или тайм-аут прерывают запуск с кодом **1**. Итоговая скорость для неполного запуска не выводится; ранее полученный прогресс остаётся видимым.
- Пустое успешное тело учитывается как 0 байт. Такой ресурс не подходит для оценки пропускной способности.
- Перенаправления обрабатываются стандартным `fetch`. Под десятью запросами понимаются десять последовательных операций скачивания; перенаправления могут добавить HTTP-обращения.
- Соединениями управляет стандартный пул `fetch`; повторное использование соединений не отключается. Отдельного прогрева нет: первый запрос входит в среднее.


## Структура

- `src/measure.mjs` — скачивание, тайм-аут и расчёт статистики.
- `src/cli.mjs` — аргументы командной строки, десять последовательных запросов и вывод.
